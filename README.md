# 冒険者の資産帳(無料版)

今の資産で過去の暴落をもう一度迎えたら、HPはいくら残るかを試算する「暴落サバイバル診断」と、FX・信用口座ごとのロスカット/追証までの距離を表示するブラウザツールです。

- 公開ページ: https://logicvtubeinvestor-bit.github.io/adventurers-ledger/
- 入力したデータや取り込んだCSVはブラウザの中だけで処理し、外部に送信しません。
- 試算は過去の値動きをもとにした厳しめの想定で、売買・税務の助言ではありません。
